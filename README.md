# Desafio Matemático - 6º Ano (Python)

Projeto desenvolvido para unir conceitos de **Educação Matemática** e **Desenvolvimento de Software**, oferecendo uma ferramenta interativa em linha de comando (CLI) para estudantes do 6º ano do Ensino Fundamental praticarem conteúdos essenciais de forma gamificada.

## Funcionalidades
- **Três níveis de dificuldade:**
  - *Nível 1:* Expressões numéricas (prioridade entre adição e multiplicação).
  - *Nível 2:* Divisão exata, múltiplos e divisores.
  - *Nível 3:* Cálculo de fração de uma quantidade inteira.
- **Geração dinâmica de questões:** Uso da biblioteca `random` para criar desafios diferentes a cada partida.
- **Sistema de pontuação e feedback:** Avaliação imediata a cada rodada e mensagem de desempenho ao final das 5 questões.
- **Tratamento de exceções:** Validação de entradas com blocos `try/except` para impedir falhas caso o usuário digite caracteres não numéricos.

## Tecnologias e Conceitos Aplicados
- **Linguagem:** Python 3
- **Estruturas:** Funções modularizadas, laços de repetição (`for` e `while`), estruturas condicionais (`if/elif/else`) e tratamento de exceções (`ValueError`).
